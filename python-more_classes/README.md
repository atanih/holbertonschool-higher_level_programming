# Python - More Classes and Objects

Holberton School project about classes, objects and OOP in Python.

## Description

This directory builds a Rectangle class step by step: from an empty class
to one with properties, area and perimeter, string representations,
instance counting, a custom print symbol, a static comparison method and
a class method that returns a square.

## Requirements

* Ubuntu 20.04 LTS with python3 (version 3.8.5)
* All files are executable and start with #!/usr/bin/python3
* The code follows pycodestyle 2.7.*
* Every module, class and method is documented
* No module may be imported

## Files

| File | Description |
| --- | --- |
| 0-rectangle.py | Empty Rectangle class |
| 1-rectangle.py | Rectangle with width and height properties |
| 2-rectangle.py | Adds area() and perimeter() |
| 3-rectangle.py | Adds __str__ |
| 4-rectangle.py | Adds __repr__ |
| 5-rectangle.py | Adds __del__ |
| 6-rectangle.py | Adds number_of_instances |
| 7-rectangle.py | Adds print_symbol |
| 8-rectangle.py | Adds bigger_or_equal static method |
| 9-rectangle.py | Adds the square class method |
