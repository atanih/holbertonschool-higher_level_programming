Python - if/else, loops, functions

Second project of the Higher Level Programming track at Holberton School. It covers indentation, conditional statements, loops, comments, functions, scope, tracebacks and arithmetic operators in Python 3.

Requirements
Ubuntu 20.04 LTS, python3 (version 3.8.x)
All files end with a new line
The first line of every file is exactly #!/usr/bin/python3
Code follows the pycodestyle style guide (version 2.7.x)
All files are executable
Files
File	Description
0-positive_or_negative.py	Prints whether a random number is positive, negative or zero
1-last_digit.py	Prints the last digit of a random number and compares it to 5 and 0
2-print_alphabet.py	Prints the lowercase alphabet using one loop and one print
3-print_alphabt.py	Prints the lowercase alphabet without the letters q and e
4-print_hexa.py	Prints the numbers 0 to 98 in decimal and hexadecimal
5-print_comb2.py	Prints the numbers 00 to 99, comma separated, two digits each
6-print_comb3.py	Prints every combination of two different digits
7-islower.py	islower(c) returns True if the character is lowercase
8-uppercase.py	uppercase(str) prints a string in uppercase
9-print_last_digit.py	print_last_digit(number) prints and returns the last digit
10-add.py	add(a, b) returns the sum of two integers
11-pow.py	pow(a, b) returns a to the power of b
12-fizzbuzz.py	fizzbuzz() prints the numbers 1 to 100, Fizz Buzz style
