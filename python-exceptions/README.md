# Python - Exceptions

Project of the Higher Level Programming track at Holberton School.
It covers errors versus exceptions, handling exceptions with
`try` / `except` / `finally`, raising built-in exceptions, and clean-up
actions.

## Requirements

* Ubuntu 20.04 LTS, python3 (version 3.8.5)
* All files end with a new line
* The first line of every file is exactly `#!/usr/bin/python3`
* Code follows the pycodestyle style guide (version 2.7.x)
* All files are executable
* No module imports are allowed

## Files

File	Description

0-safe_print_list.py	safe_print_list(my_list=[], x=0) prints x elements of a list and returns how many were printed

1-safe_print_integer.py	safe_print_integer(value) prints an integer with "{:d}".format(), returns True or False

2-safe_print_list_integers.py	safe_print_list_integers(my_list=[], x=0) prints only the integers among the first x elements

3-safe_print_division.py	safe_print_division(a, b) divides two integers and prints the result in a finally block

4-list_division.py	list_division(my_list_1, my_list_2, list_length) divides two lists element by element

5-raise_exception.py	raise_exception() raises a TypeError

6-raise_exception_msg.py	raise_exception_msg(message="") raises a NameError with a message
