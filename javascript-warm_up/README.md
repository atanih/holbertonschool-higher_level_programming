# JavaScript - Warm up

Introducción a JavaScript como lenguaje de scripting, ejecutado con Node.js
en la línea de comandos.

## Objetivos

- Crear variables y constantes con `let` y `const`, sin usar `var`
- Conocer los tipos de datos de JavaScript
- Usar condicionales `if` / `if ... else`
- Usar bucles `while` y `for`, con `break` y `continue`
- Definir y usar funciones, y entender el ámbito de las variables
- Manipular objetos y arreglos
- Importar archivos

## Requisitos

- Ubuntu 20.04 LTS con Node.js 14
- Todos los archivos empiezan por `#!/usr/bin/node`
- Todos los archivos terminan con un salto de línea
- Todos los archivos son ejecutables
- El código cumple con `semistandard` (Standard + punto y coma)

## Archivos

| Archivo | Descripción |
|---|---|
| `0-javascript_is_amazing.js` | Imprime "JavaScript is amazing" usando una constante |
| `1-multi_languages.js` | Imprime tres líneas: C, Python y JavaScript |
